# Changelog

## [0.2.1] - 2026-11-03

- Added live severity counters for ERROR, WARN, and FATAL.
- Added case-insensitive search highlighting and previous/next result navigation.
- Added TXT error-report export with related exception and stack-trace lines.
- Improved Live Monitor with filesystem notifications and a polling fallback.
- Added buffering for incomplete lines and partial UTF-8 sequences.
- Added custom frameless window controls, purple glow states, custom checkboxes, and navy scrollbars.

## [0.2.0] - 2026-11-03

- Added severity overview, enhanced search, report export, and initial Live Mode.
- Added a custom frameless window and glow styling.

## [0.1.0] - 2026-11-02

- Initial WPF log viewer with filters, search, and an entry inspector.
